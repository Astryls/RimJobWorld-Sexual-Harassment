# RimJobWorld - Sexual Harassment

An addon for RimJobWorld that adds emergent sexual harassment: pawns catcall, proposition, grope, and (when enabled) escalate to forced acts against vulnerable targets. Dynamic dialogue through SpeakUp and RimTalk when present, karma consequences through Karma &amp; Reputation, and a player intervene prompt before things turn physical. Fully configurable who-harasses-whom matrix.
